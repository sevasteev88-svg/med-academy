# MedAcademy: правила проекта

Стек: Next.js (App Router), TypeScript, Tailwind v4 (токены в @theme в globals.css), Supabase (Auth, Postgres, RLS), Recharts.
Язык интерфейса: только украинский. Комментарии в коде и ответы агента: русский.
Маршруты: корневые, без [locale].

Архитектура:
- Все мутации БД только в src/actions/*-action.ts ("use server"). Компоненты не пишут в Supabase напрямую.
- Серверный клиент: src/utils/supabase/server.ts, браузерный: client.ts.

Безопасность:
- Никаких секретов в коде. Не логировать персональные данные.
- Service-role ключ только на сервере.

База данных:
- Изменения схемы только файлами миграций в supabase/migrations/ (SQL).
- Никогда не выполнять миграции и команды против production.

Медицинские данные:
- Никаких значений по умолчанию, которые выглядят как результат обследования. Нет данных = "Немає даних".
- Все пороги и нормы в одном файле констант с комментарием-источником.
- Не придумывать медицинские или юридические формулировки. Если нужен текст, ставить пометку «потребує перевірки лікарем/юристом».

Порядок работы:
1. Сначала изучи репозиторий и покажи план. Код после утверждения.
2. После изменений запусти typecheck, lint, build.
3. Не оставляй console.log и тестовые данные.
4. Не рефактори несвязанный код.
5. В конце дай walkthrough: что изменено, как проверить, что не сделано.
